## 竞争检测

```powershell
docker run --rm --add-host=host.docker.internal:host-gateway `
  -e 'PET_MYSQL_TEST_DSN=root:<redacted>@tcp(host.docker.internal:3306)/?parseTime=true' `
  -v "${workspace}:/app:ro" -w /app golang:1.26 `
```
