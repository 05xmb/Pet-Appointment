# DEV03 模拟支付阶段记录

- 时间：2026-11-13（北京时间）
- 范围：支付意图、固定金额、HMAC-SHA256 回调、成功/失败/超时/重复通知、关闭后迟到支付异常。
- 依赖：DEV01 会话/时钟和 DEV02 预约占位。
- 未包含：退款发起与退款回调（DEV04）、临近取消审核、核销、履约、未到店、日清和最终页面。

## 实际验证

| 检查 | 结果 |
|---|---|
| RED：支付领域与 MySQL 测试 | 先因 `payment` 类型、迁移表和方法不存在而失败，随后最小实现 |
| 领域/HMAC 单测 | 原始报文签名校验、错误签名和业务错误传播通过 |
| MySQL 集成 | 随机测试库通过：支付意图幂等、成功确认、失败/超时不确认、重复成功幂等、关闭后迟到成功写 `LATE_PAYMENT/NEEDS_REFUND`、过期支付先关闭预约再拒绝 |
| HTTP 单测 | 固定金额不接受请求金额、回调必须 HMAC、错误签名不落库、重复回调可重复查询 |

## 当前限制

- `exceptions` 只登记迟到支付待退款，退款记录和退款回调尚未实现。
- 正式服务必须设置 `PET_PAYMENT_HMAC_SECRET`；密钥不提交、不写日志、不回显。
- DEV04–DEV06、独立测试/验收、纯单元覆盖率、HTTPS/TLS 发布和部署证据仍未完成。
